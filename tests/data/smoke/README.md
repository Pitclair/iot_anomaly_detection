# LM-IDNet public smoke fixture

`synthetic_packet_counts.json` was created specifically for this repository. It
contains synthetic timestamps and protocol labels only. It contains no packet
payloads, endpoint addresses, MAC addresses, hostnames, or identifiers copied
from the research captures.

The fixture is dedicated to the public domain under SPDX license identifier
`CC0-1.0`. It may be copied, modified, and redistributed for testing.
