\begin{abstract}
This report describes the complete current LM-IDNet project: its statistical
model, data preparation, native numerical backend, static and adaptive
detectors, input safeguards, saved-state mechanism, streaming runtime, simulated
edge deployment, tests, research branches, and thesis-writing workspace.
It retains the earlier experiments, including unsuccessful ones, while
identifying which implementation and adaptation policy produced each result.
The reference software now supports conservative updates, restoration and
rollback, and bounded supplied-window operation in a local Docker simulation.
The scientific evidence remains more limited than the implementation: the
labelled reference comparisons are development results, the conservative
comparison reports still need a definitive run, and the reference command line
does not yet expose the reserved final-test partition. The report is intended
as a technical and experimental reference for writing the thesis, rather than
as a substitute for the thesis or a claim of production deployment.
\end{abstract}
